# Sales & Revenue Analysis Dashboard

## Project Overview

This project is a Power BI dashboard developed to analyze sales and revenue data and generate business insights.

## Tools Used

* Power BI
* Excel/CSV Dataset

## Features

* Total Sales KPI
* Revenue Analysis
* Top Performing Products
* Interactive Filters and Slicers
* Sales Trend Visualization
* Business Insight Generation
